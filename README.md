## 📌 Descripción del Sistema
Este repositorio aloja la documentación técnica y estratégica correspondiente al **Módulo de Seguimiento de Flotas e Inventario en Tiempo Real** para la empresa **SSServicios S.A.**[cite: 4, 9, 13] El sistema está diseñado como una solución SaaS integral que permite a empresas PyME rastrear sus unidades logísticas mediante geolocalización por sensores IoT/GPS y actualizar de manera automatizada el stock de insumos en tiempo real[cite: 7, 8].
